// Martina Trillini — Full Stack Dev
class Developer {

  private $stack = [
    "backend"  => ["PHP", "MySQL", "REST API"],
    "frontend" => ["JS", "HTML", "CSS"],
    "design"   => ["Figma", "UX/UI"],
  ];

  public function build($idea) {
    $ux  = $this->design($idea);
    $api = $this->develop($ux);
    return $this->deploy($api);
  }

}

Sobre mí

✦ Mi enfoque

  • UX/UI basado en evidencia

    Investigo antes de diseñar. Entrevistas, user journeys y pruebas de usabilidad guían cada decisión.

  • Diseño que se puede construir

    Mi perfil técnico me permite definir criterios precisos y colaborar con desarrollo sin fricciones.

  • Backend estructurado

    Arquitectura modular, bases de datos normalizadas y consultas que escalan.

  • Resolución de problemas reales

    Foco en el proceso de negocio y en el usuario, no solo en que funcione.

⚙ Cómo trabajo

  1. 01
    Investigo el problema

    Entrevistas, relevamiento de necesidades y análisis de comportamiento.

  2. 02
    Diseño el flujo

    User journeys, wireframes y prototipos en Figma con arquitectura clara.

  3. 03
    Modelo la base de datos

    Tablas, relaciones y estados bien definidos antes de escribir código.

  4. 04
    Desarrollo la lógica

    PHP estructurado, módulos independientes, REST APIs documentadas.

  5. 05
    Pruebo y optimizo

    Pruebas de usabilidad, optimización SQL y refactoring cuando es necesario.
